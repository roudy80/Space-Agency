# Space Agency Command

A space agency management game inspired by Tiny Space Agency, KSP, and Mars survival games.

## 🎮 Play the Game

Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).

## 🚀 Features

### Core Gameplay
- **Research System**: Unlock new rockets, destinations, and technologies
- **Mission Launches**: Send probes, crew, and base modules to space
- **Astronaut Corps**: Hire and manage astronauts with mission tracking
- **Contracts**: Complete government contracts for funding
- **Multiple Destinations**: LEO, Moon, Mars, Venus, Jupiter
- **Base Building**: Establish permanent bases on Moon and Mars
- **Reusable Rockets**: Research space planes and reusable technology

### Tech Tree Categories
- **Rockets**: Small → Medium → Heavy → Super Heavy
- **Reusable**: Space Planes and Reusable Rockets (50% cost savings)
- **Destinations**: Unlock Moon, Mars, Venus, Jupiter missions
- **Crew**: Human spaceflight and landing capabilities
- **Bases**: Space stations and planetary bases
- **Mining**: Extract resources from bases for income

### Game Mechanics
- Start with $1,000,000 budget
- Hire astronauts for $50,000 each
- Launch missions with real-time countdowns (10s-300s)
- 95% mission success rate
- Complete contracts for rewards and reputation
- Auto-save every 30 seconds
- Works on phone and desktop

## 🎯 Progression Path

1. **Early Game**
   - Launch small probes to LEO
   - Research human spaceflight
   - Hire first astronauts
   - Complete LEO contracts

2. **Mid Game**
   - Research medium rockets and Moon missions
   - Land crew on Moon
   - Build Moon base
   - Unlock Mars program

3. **Late Game**
   - Establish Mars base
   - Research mining technologies
   - Unlock Venus and Jupiter missions
   - Build reusable space plane fleet

## 🎨 Design

8-bit retro aesthetic with green/cyan terminal colors on dark space-themed background.

## 💾 Save System

Game automatically saves every 30 seconds to browser localStorage. Your progress persists between sessions.

## 🛠️ Technical Stack

- Pure HTML5/CSS3/JavaScript
- No dependencies or frameworks
- Fully client-side
- Mobile responsive

## 🎲 Tips

- Don't rush! Build up budget with LEO missions first
- Contracts are lucrative but require specific mission types
- Research reusable rockets to cut costs 50%
- Astronauts track their own stats (missions, time in space)
- Mining bases generate passive income
- Refresh contracts for $10k to get new opportunities

Enjoy building your space empire! 🚀🌙🔴
